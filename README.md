# 거래처별 매출 대시보드

엑셀 파일(시트 2개)을 업로드하면 거래처별 연도 매출과 품목별 상세, 브리핑용 문구를 보여주는 **단일 HTML 대시보드**입니다.
서버가 없고, 엑셀 데이터는 **브라우저 안에서만 처리되며 외부로 전송되지 않습니다.**

## 사용법
1. `index.html`을 브라우저에서 열거나 GitHub Pages 주소로 접속합니다.
2. 엑셀 파일을 끌어다 놓거나 "파일 선택"을 누릅니다. ("샘플 데이터로 보기"로 먼저 확인할 수 있습니다.)
3. 거래처(여러 개 선택 가능) · 연도 · Fiscal MM을 고르면 결과가 즉시 갱신됩니다.

## 기능
- 거래처별 연도 매출(만원)과 판매 대수
- Y2627 품목별 판매량 · 매출 · 비중 · ASP, 월별 수량 히트맵, CSV 다운로드
- 핵심 품목 설정(이름 · 약칭 수정, 느슨한 이름 매칭, 후보 지정)
- 거래처별 브리핑 문구 자동 생성 + 복사
- 다크모드, 모바일 대응(품목명 열 고정)

## 엑셀 형식
- `납품처코드`, `납품처명`, (품목 시트) `품목명`, `합계: Sales`, `합계: Unit`, `Fiscal Year`(예: Y2627), `Fiscal MM`(1=4월 … 12=3월)
- 피벗 형태와 세로(평면) 형태를 모두 인식하고, 컬럼명의 공백·대소문자 차이는 허용합니다.

## 개인정보 / 데이터
- 이 저장소에는 실제 매출 데이터를 올리지 마세요. (`.gitignore`가 엑셀·CSV 파일을 제외합니다.)
- 핵심 품목 설정은 사용자의 브라우저(localStorage)에만 저장됩니다.

## 기술
- 순수 HTML/CSS/JS 한 파일, 엑셀 읽기는 [SheetJS](https://sheetjs.com) 0.18.5 (cdnjs)
